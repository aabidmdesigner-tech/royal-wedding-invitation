# Royal Wedding Invitation

A mobile-first cinematic royal Indian wedding invitation built as a static HTML/CSS/JS site.

## Flow
1. Opening palace-door reveal
2. Hero
3. Countdown
4. Celebrations
5. Venue
6. Gallery
7. Family
8. Map

## Customize
Edit `index.html` for names, dates, venue and copy.
Edit the `target` date in `script.js` for the countdown.
Replace the CSS-generated gallery blocks with real photos when ready.

## GitHub Pages
Upload the project contents to your repository and enable:
Settings → Pages → Deploy from branch → main → / (root).
